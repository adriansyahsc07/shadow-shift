**Shadow Shift** — a top-down stealth game: sneak through three night-time museum halls, slip past patrolling guards and their vision cones, hide in bushes, crouch behind crates, toss pebbles to lure guards away, grab the loot (and the gold keycard on level 3), and reach the green exit unseen. WASD/arrows to move, Shift to sneak, click to throw a pebble; synthesized WebAudio footsteps, alarm stings and chimes; fully offline, no libraries.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser and play
# or hand the entry in:
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
